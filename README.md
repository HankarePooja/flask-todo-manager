# MyTodo flask based web application

A Flask Todo application with secure user authentication using Google OAuth.
Designed to demonstrate backend fundamentals, CRUD operations, and deployment best practices.

🚀 Features :
- Google OAuth–based user authentication
- Create, update, and delete todo items (CRUD)
- Secure session and token handling
- Environment-based secrets management
- Production deployment with Gunicorn

🛠 Tech Stack :
- Flask
- SQLAlchemy
- Authlib (OAuth 2.0)
- SQLite
- Gunicorn

🌐 Deployment
- Deployed on Render using environment variables for secure configuration.
- 🔗 Live Demo: https://flask-todo-manager-ivde.onrender.com
